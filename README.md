# :earth_americas: GDP dashboard template

A simple Streamlit app showing the GDP of different countries in the world.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://gdp-dashboard-template.streamlit.app/)

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```

## Hồ sơ chất lượng xây dựng (QA/QC)

`qaqc_app.py` là ứng dụng quản lý hồ sơ chất lượng: biên bản nghiệm thu vật liệu / công việc / giai đoạn,
checklist, nhật ký thi công và xuất danh mục Excel. Dữ liệu lưu ở `data/qaqc/records.json`.

```
$ streamlit run qaqc_app.py
```
